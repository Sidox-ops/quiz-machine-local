# Roadmap

This roadmap describes direction rather than a delivery promise. Priorities may
change as real-world model and platform reports arrive.

## Before the first signed release

- keep public CI green across backend, Flutter, macOS and Windows builds;
- validate signed and notarized packages on clean user accounts;
- expand the model compatibility matrix with reproducible probe and generation
  timings;
- complete a keyboard, screen-reader, scaling, and contrast pass;
- add a native PowerShell development launcher.

## Later

- opt-in local benchmark history for better per-machine recommendations;
- additional UI languages;
- a privacy-preserving diagnostics export reviewed by the user before sharing;
- a signed update channel with explicit user control;
- broader certification coverage driven by validated Microsoft Learn scopes.

Hosted accounts, mandatory telemetry, automatic model downloads, and a
publisher-operated question service are not planned without an explicit public
product and privacy decision.
