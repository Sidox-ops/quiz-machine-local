# Support

Quiz Machine Local is maintained as a community open-source project. There is no
guaranteed response time, service-level agreement, or private support channel.

## Where to ask

- Use GitHub Discussions for setup questions, model experience reports, and
  ideas that are not yet actionable bug reports.
- Open a bug report for reproducible defects after checking existing issues.
- Report security vulnerabilities privately according to `SECURITY.md`; do not
  disclose exploit details in a public issue.

## Information to include

Provide the Quiz Machine version, operating system and architecture, Flutter and
Python versions for source builds, Ollama version, selected model name and
quantization, and the exact visible error. State whether the Microsoft Learn MCP
check completed.

Do not attach imported corpora, generated question banks, progress files,
credentials, signing material, complete environment dumps, or Ollama model
files. Remove usernames and local paths from logs before sharing them.

## Supported scope

Maintainers prioritize regressions in the latest release, data loss, security or
privacy boundary failures, onboarding blockers, and reproducible failures on the
platforms listed in `docs/COMPATIBILITY.md`. Model-specific quality issues may
need confirmation from another user with the same model digest and hardware.
